# **App Name**: Agent Central

## Core Features:

- Agent Aggregation: Aggregate and display data from AnnabanAI, SparkAI, SparkOS, AetherOS, Gemini, Claude, Perplexity, Claude, and ChatGPT into a single dashboard.
- Agent Status Monitoring: Display the current status (active, idle, error) of each agent in real-time.
- Task Summarization: Use an AI tool to summarize the last completed tasks for each agent, including key outcomes.
- Performance Metrics: Show key performance metrics such as task completion rate, error rate, and average processing time for each agent.
- Alerting: Set up alerts for when an agent encounters an error or goes offline.
- Logs Viewer: Provide a consolidated view of logs from each agent, with filtering options.

## Style Guidelines:

- Primary color: Dark blue (#30475E) for a professional and serious look.
- Background color: Dark gray (#222831), near the primary color in hue but heavily desaturated for contrast.
- Accent color: Orange (#F05454) for alerts and highlights; an analogous hue but much brighter.
- Headline font: 'Space Grotesk', sans-serif. Body font: 'Inter', sans-serif.
- Use minimalist icons to represent different agent types and statuses.
- Dashboard layout with clear sections for each agent, metrics, and alerts.
- Subtle transitions and animations for loading data and updating statuses.
